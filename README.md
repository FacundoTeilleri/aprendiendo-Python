## 📖 Sobre este repositorio

Este repositorio reúne los ejercicios y proyectos prácticos que voy creando a medida que aprendo Python. La idea es documentar mi progreso, practicar buenas prácticas y construir aplicaciones reales, desde scripts simples hasta programas con interfaz gráfica.

- **Python 3**: lenguaje principal y sus respectivas librerías
- **Tkinter**: interfaces gráficas de escritorio
- **Git y GitHub**: control de versiones

## ▶️ Cómo ejecutar los proyectos

1. Cloná el repositorio:
   ```bash
   git clone https://github.com/FacundoTeilleri/aprendiendo-Python.git
   ```
2. Entrá a la carpeta del proyecto que quieras probar:
   ```bash
   cd aprendiendo-Python/nombre-del-proyecto
   ```
3. Instalá las dependencias, si el proyecto las tiene:
   ```bash
   pip install -r requirements.txt
   ```
4. Ejecutá el programa:
   ```bash
   python main.py
   ```

> 📌 Cada proyecto puede tener pasos propios. Revisá siempre su `README.md`.

## 🖥️ Aplicaciones con Tkinter

Para abrir correctamente las aplicaciones creadas con Tkinter, ejecutá cada una **como administrador**. Así se evitan problemas de permisos al iniciarlas.

## 🔑 Uso de APIs y claves

- Las **API Keys** que uso son oficiales de cada plataforma.
- En el `README.md` de cada proyecto se describe qué API se utiliza y para qué.
- Las claves **privadas no se publican** en el repositorio. Para usarlas, creá tu propia clave y guardala en un archivo `.env` (incluido en `.gitignore`) en lugar de escribirla directamente en el código.
