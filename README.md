# Aprendiendo Python

Ejercicios y proyectos de Python que voy haciendo mientras estudio programación.

## Contenido

- **Calculadora multifunción:** calculadora hecha en Python que resuelve varias operaciones.
- **Agenda con Google Calendar:** aplicación de escritorio para guardar hábitos, cumpleaños y tareas, conectada a la API de Google Calendar. Usa Tkinter para la interfaz y SQLite para guardar los datos.

## Tecnologías

- Python
- Tkinter
- SQLite
- API de Google Calendar
- Git y GitHub

## Cómo ejecutarlo

Descargá el repositorio y ejecutá el archivo que quieras probar:

    python nombre_del_archivo.py
